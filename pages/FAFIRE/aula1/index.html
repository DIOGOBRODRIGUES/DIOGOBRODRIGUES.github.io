Panorama do Desenvolvimento Mobile

O mercado de aplicativos móveis continua em expansão, com mais de 3,8 bilhões de usuários de smartphones no mundo.

  • 🔹 Principais plataformas: Android e iOS

Combina tecnologias web com componentes nativos

💡 O React Native usa "bridges" para traduzir componentes JS em elementos nativos reais.

React Native: Nova Arquitetura

O modo Bridgeless

  • JSI (JavaScript Interface): Comunicação direta entre JavaScript e código nativo, sem serialização em JSON

💡 A Nova Arquitetura reduz o custo de comunicação da antiga Bridge, ajudando a evitar gargalos em interações frequentes com o lado nativo.

🏗️ Padrões de Arquitetura em Aplicações

Organizam o código de forma escalável, facilitam manutenção e colaboração em equipe.

  • ✅ Separação de responsabilidades
  • 🔄 Fluxo claro de dados
  • 🧪 Facilidade de testes
  • 🧠 Escalabilidade do projeto

📌 Qual arquitetura escolher?

Depende do tamanho da aplicação, equipe e objetivos:

  • 👶 Pequenos projetos: MVC, MVVM
  • 👨‍💻 Equipes médias: MVP, Redux
  • 🏢 Grandes sistemas: Clean Architecture, Feature-based

📊 Comparação entre Padrões de Arquitetura

Padrão Camadas Principais Fluxo de Dados Responsabilidade da UI Complexidade Indicado para
MVC Model / View / Controller Bidirecional Controlada parcialmente pelo Controller 🟡 Média Apps simples e médios
MVVM Model / View / ViewModel Bidirecional (com binding) Reativa via ViewModel 🟠 Alta Apps com interface reativa (Flutter, Angular)
MVP Model / View / Presenter Bidirecional Totalmente passiva 🟡 Média Apps testáveis com UI desacoplada
Clean Arch Entidades / Casos de Uso / Adaptadores / UI Unidirecional (controlado por regras) Camada mais externa 🔴 Alta Apps grandes e escaláveis
Redux/Flux Store / Action / Reducer / View Unidirecional Atualizada pela Store 🟠 Alta Gerenciamento global de estado

Performance em Aplicativos Móveis

A performance é um dos fatores mais críticos para retenção de usuários

  • ⚡ Tempo de inicialização: Deve ser inferior a 2 segundos
  • 📊 Gerenciamento de memória: Evitar vazamentos e uso excessivo
  • 🔄 Taxa de quadros: Manter 60fps para animações fluidas
  • 🔋 Consumo de bateria: Otimizar uso de recursos
  • 📡 Consumo de dados: Minimizar transferência, implementar cache
  • 📴 Funcionalidade offline: Planejar para uso sem conexão

Segurança em Aplicativos Móveis

  • 🔐 Autenticação: Biometria, 2FA, OAuth
  • 📶 Comunicação segura: HTTPS, certificados pinning
  • 🛡️ Proteção de código: Ofuscação, anti-tampering
  • 📝 Validação de entrada: Sanitização de dados do usuário
  • 🔓 Jailbreak/Root: Detecção de dispositivos comprometidos

📱 Módulo 2: React Native e Expo

Desenvolvimento mobile multiplataforma

Introdução ao React Native

  • Framework JavaScript para desenvolvimento nativo
  • Mesmo conceito do React, diferente implementação
  • Componentes nativos vs. componentes web
  • Escreva uma vez, rode em iOS e Android
  • Renderiza componentes nativos reais, não WebView

🔄 React (web): div, span, h1, p, button

📱 React Native: View, Text, TouchableOpacity

Como o React Native Funciona

Tradução de componentes React em Views nativas

Expo: Desenvolvimento Simplificado

  • Conjunto de ferramentas para React Native
  • Facilita configuração, desenvolvimento e publicação
  • Acesso a APIs nativas sem configuração
  • Desenvolvimento com Expo Go (preview no dispositivo)
  • Expo Snack: ambiente online de desenvolvimento

💡 Expo SDK: Conjunto de APIs nativas prontas para uso (câmera, localização, notificações, etc)

📱 Construindo Meu Primeiro App com React Native

Vamos criar um app simples com um botão que incrementa um contador!

  • ✔️ Expo
  • ✔️ React Native
  • ✔️ useState
  • ✔️ StyleSheet

⚙️ Passo 1 – Criar Projeto Expo

npx create-expo-app meu-app --template

Depois:

cd meu-app
          npx expo start

📁 Passo 2 – Estrutura Inicial

No arquivo App.js, vamos criar a estrutura do app:

import React, { useState } from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

🧠 Passo 3 – Criar estado do contador

Declaramos a variável contador com useState:

const [contador, setContador] = useState(0);

Isso permite atualizar o valor exibido na tela dinamicamente.

🧩 Passo 4 – Interface com View, Text e Button

🎨 Passo 5 – Estilos com StyleSheet

O React Native usa objetos JS no lugar do CSS tradicional.

const styles = StyleSheet.create({
            container: {
              flex: 1,
              justifyContent: 'center',
              alignItems: 'center',
              backgroundColor: '#f5f5f5',
            },
            titulo: {
              fontSize: 24,
              fontWeight: 'bold',
              marginBottom: 20,
            },
            contador: {
              fontSize: 18,
              marginBottom: 20,
            },
          });

✅ Resultado Final

  • Tela centralizada com fundo claro
  • Texto grande com título
  • Contador reativo com botão "Incrementar"

🎉 Parabéns, seu primeiro app está pronto!
