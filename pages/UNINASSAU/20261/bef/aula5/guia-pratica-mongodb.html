Tutorial prático com MongoDB Atlas

Como implementar favoritos a partir do código base

Este tutorial foi escrito para um cenário em que o projeto base ainda não tem a funcionalidade de favoritos. A ideia é que façam as alterações por etapas e cheguem a uma API capaz de salvar, listar e remover Pokémons favoritos no MongoDB Atlas.

Objetivo Construir a feature do zero
Backend Express + TypeScript
Banco MongoDB Atlas com upsert

1. Proposta

A base do projeto já possui a busca de Pokémon e a rota de batalha. Nesta atividade, os alunos vão adicionar uma segunda camada de dados: favoritos persistidos no banco. Ao final, a aplicação terá uma coleção dedicada no MongoDB Atlas, com rotas REST para criar, consultar e excluir favoritos.

2. Passo a passo para implementar

  • 1

    Entender o ponto de partida

    O projeto base já tem o servidor Express em src/server.ts e o serviço que busca dados na PokeAPI. Antes de mexer, os alunos devem identificar onde as rotas atuais vivem e onde será mais natural encaixar a nova funcionalidade.

  • 2

    Instalar o driver do MongoDB

    O primeiro passo prático é abrir o terminal na pasta do projeto e instalar mongodb e dotenv. Isso prepara a aplicação para se conectar ao Atlas sem colocar credenciais diretamente no código. 

    npm install mongodb dotenv
  • 3

    Criar a conta e o cluster no MongoDB Atlas

    O aluno deve acessar o MongoDB Atlas, criar uma conta, gerar um cluster gratuito e liberar o acesso do IP da máquina usada na aula. Depois disso, ele precisa copiar a string de conexão e guardar esse valor no arquivo .env.

    O arquivo .env.example serve só como molde para mostrar quais variáveis o projeto precisa receber.

  • 4

    Criar os arquivos da solução

    Em vez de espalhar código de banco no servidor, a prática pede que os alunos criem arquivos separados. O mais importante é src/services/favoritesService.ts, mas também vale garantir o .env.example e, se necessário, ajustar src/server.ts. 

    src/
  server.ts
  services/
    pokemonService.ts
    battleService.ts
    favoritesService.ts
  • 5

    Adicionar as rotas REST

    Depois que o serviço estiver pronto, os alunos devem ligar isso ao servidor com três rotas novas: GET /favorites, POST /favorites e DELETE /favorites/:name. Assim, a API ganha o fluxo completo de CRUD mínimo para a atividade.

    Cada rota deve devolver uma resposta clara, com status HTTP coerente, para que o aluno consiga testar o comportamento facilmente.

  • 6

    Testar e validar

    A etapa final é testar a API usando navegador, Insomnia, Postman ou Thunder Client. O aluno deve verificar se os favoritos realmente aparecem no MongoDB Atlas e se a API responde com os status corretos.

3. Fluxo que os alunos devem implementar

Leitura da PokeAPI

O backend continua usando a PokeAPI para buscar o Pokémon original. Esse dado é a base para criar o favorito que será salvo no banco.

Gravação no MongoDB

Quando o aluno chamar POST /favorites, a aplicação deve gravar ou atualizar o Pokémon na coleção favorite_pokemons usando upsert. Isso evita duplicidade e simplifica o exercício.

O uso de nome normalizado evita duplicidade com variações como Pikachu, pikachu ou PIKACHU, o que é excelente para explicar modelagem de dados na aula.

Arquivo 2 - src/services/favoritesService.ts

import { MongoClient, type Collection } from 'mongodb';
// Importa o cliente do MongoDB e o tipo Collection para tipagem
// Essas importações permitem conectar ao banco e manipular coleções
import type { PokemonData } from './pokemonService';

export type FavoritePokemon = PokemonData & {
  favoriteId: string;
  createdAt: string;
  updatedAt: string;
};

type FavoritePokemonDocument = PokemonData & {
  normalizedName: string;
  createdAt: Date;
  updatedAt: Date;
};

const mongoUri = process.env.MONGODB_URI;
const databaseName = process.env.MONGODB_DB ?? 'pokemon-backend';
const collectionName = 'favorite_pokemons';

let client: MongoClient | null = null;
let collectionReady: Promise> | null = null;

const getCollection = async (): Promise> => {
  if (!mongoUri) {
    // Verifica se a variável de ambiente com a URI do MongoDB está definida
    // Se não estiver, aborta com erro para evitar tentativa de conexão inválida
    throw new Error('MONGODB_URI não configurada');
  }

  if (!collectionReady) {
    // Cria uma nova instância do MongoClient e inicia a conexão uma única vez
    // A promise collectionReady garante que a inicialização da coleção
    // (e criação de índice) ocorra apenas na primeira chamada
    client = new MongoClient(mongoUri);
    collectionReady = client.connect().then(connection => {
      // Seleciona o banco e a coleção onde os favoritos serão armazenados
      const collection = connection.db(databaseName).collection(collectionName);

      // Cria um índice único em normalizedName para evitar duplicatas por nome
      return collection.createIndex({ normalizedName: 1 }, { unique: true }).then(() => collection);
    });
  }

  return collectionReady;
};

const serializeFavorite = (document: FavoritePokemonDocument & { _id: unknown }): FavoritePokemon => ({
  favoriteId: String(document._id),
  id: document.id,
  name: document.name,
  types: document.types,
  stats: document.stats,
  createdAt: document.createdAt.toISOString(),
  updatedAt: document.updatedAt.toISOString()
});

export const saveFavoritePokemon = async (pokemon: PokemonData): Promise => {
  const collection = await getCollection();
  const now = new Date();
  const normalizedName = pokemon.name.toLowerCase();

  // Usa updateOne com upsert para inserir ou atualizar o documento do favorito
  // $set atualiza os campos sempre que já existir, $setOnInsert define createdAt apenas na primeira inserção
  await collection.updateOne(
    { normalizedName },
    {
      $set: {
        id: pokemon.id,
        name: pokemon.name,
        types: pokemon.types,
        stats: pokemon.stats,
        normalizedName,
        updatedAt: now
      },
      $setOnInsert: {
        createdAt: now
      }
    },
    { upsert: true }
  );

  const favorite = await collection.findOne({ normalizedName });

  if (!favorite) {
    throw new Error('Falha ao salvar favorito');
  }

  return serializeFavorite(favorite as FavoritePokemonDocument & { _id: unknown });
};

export const listFavoritePokemons = async (): Promise => {
  const collection = await getCollection();
  const favorites = await collection.find().sort({ createdAt: -1 }).toArray();

  return favorites.map(favorite => serializeFavorite(favorite as FavoritePokemonDocument & { _id: unknown }));
};

export const removeFavoritePokemon = async (name: string): Promise => {
  const collection = await getCollection();
  // Remove o documento pelo nome normalizado e retorna true se algo foi excluído
  const result = await collection.deleteOne({ normalizedName: name.toLowerCase() });

  return result.deletedCount > 0;
};

Arquivo 3 - src/server.ts

import express from 'express';
import cors from 'cors';
import { getPokemonData } from './services/pokemonService';
import { calculateBattle } from './services/battleService';
import { listFavoritePokemons, removeFavoritePokemon, saveFavoritePokemon } from './services/favoritesService';

const app = express();
app.use(cors());
app.use(express.json());

app.get('/pokemon/:name', (req, res) => {
  const { name } = req.params;

  getPokemonData(name)
    .then(pokemon => res.json(pokemon))
    .catch(error => {
      void error;
      return res.status(404).json({ error: 'Pokémon não encontrado' });
    });
});

app.get('/favorites', async (_req, res) => {
  try {
    const favorites = await listFavoritePokemons();
    return res.json(favorites);
  } catch {
    return res.status(500).json({ error: 'Não foi possível listar os favoritos' });
  }
});

app.post('/favorites', async (req, res) => {
  try {
    const { pokemon, name } = req.body as { pokemon?: { id: number; name: string; types: string[]; stats: { name: string; value: number }[] }; name?: string };

    const pokemonData = pokemon ?? (name ? await getPokemonData(name) : null);

    if (!pokemonData) {
      return res.status(400).json({ error: 'Envie o Pokémon completo ou o nome para favoritar' });
    }

    const favorite = await saveFavoritePokemon(pokemonData);
    return res.status(201).json(favorite);
  } catch {
    return res.status(500).json({ error: 'Não foi possível salvar o favorito' });
  }
});

app.delete('/favorites/:name', async (req, res) => {
  try {
    const { name } = req.params;
    const removed = await removeFavoritePokemon(name);

    if (!removed) {
      return res.status(404).json({ error: 'Favorito não encontrado' });
    }

    return res.status(204).send();
  } catch {
    return res.status(500).json({ error: 'Não foi possível remover o favorito' });
  }
});

app.post('/battle', (req, res) => {
  const { attacker, defender } = req.body;

  if (!attacker || !defender) {
    return res.status(400).json({ error: 'Dados dos lutadores são obrigatórios' });
  }

  const result = calculateBattle(attacker, defender);

  return res.json({
    battleLog: `${attacker.name} atacou ${defender.name}!`,
    ...result
  });
});

const PORT = 3333;
app.listen(PORT, () => console.log(`🚀 PokeServer rodando em http://localhost:${PORT}`));
