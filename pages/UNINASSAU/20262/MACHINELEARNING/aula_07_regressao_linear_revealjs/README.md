# Aula 7 — Regressão Linear Supervisionada

Apresentação Reveal.js autoexplicativa para uma aula de 180 minutos sobre modelagem, métricas de erro e análise de resíduos.

## Como abrir

- macOS: clique duas vezes em `iniciar.command`.
- Windows: clique duas vezes em `iniciar.bat`.
- Alternativa: inicie um servidor local nesta pasta e abra `index.html`.

## Controles

- Setas ou espaço: navegar.
- `Esc`: visão geral.
- `S`: notas do apresentador.
- `F`: tela cheia.
- `Alt` + clique: zoom.

## Arquivo da prática

- `aula_07_pratica_regressao_linear.ipynb`: notebook pronto para o Google Colab.

O pacote funciona sem internet para exibir os slides. A execução do notebook no Colab depende de conexão.
