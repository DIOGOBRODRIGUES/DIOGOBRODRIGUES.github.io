# Aula 8 — Aprendizado Não Supervisionado

Apresentação Reveal.js autoexplicativa para uma aula de 180 minutos sobre agrupamento K-means, escolha de `k`, interpretação de clusters e redução de dimensionalidade com PCA.

## Como abrir

- macOS: clique duas vezes em `iniciar.command`.
- Windows: clique duas vezes em `iniciar.bat`.
- Alternativa: inicie um servidor local nesta pasta e abra `index.html`.

## Controles

- Setas ou espaço: navegar.
- `Esc`: visão geral.
- `S`: notas do apresentador.
- `F`: tela cheia.
- `Alt` + clique: zoom.

## Arquivo da prática

- `aula_08_pratica_kmeans_pca.ipynb`: notebook pronto para Google Colab.

O pacote funciona sem internet para exibir os slides. A execução do notebook no Colab depende de conexão.
