# Agência React — material da aula de autenticação

## Para o professor

1. Abra `ROTEIRO-PROFESSOR.md`.
2. Execute `agencia-react-completa` antes da aula para revisar o resultado.
3. Use a versão completa somente como consulta durante o live coding.

## Para os estudantes

Distribua apenas a pasta `agencia-react-inicial`.

Cada trio deverá executar:

```bash
npm install
npm run dev
```

## Resultado da prática

Ao terminar, o projeto deverá possuir:

- login com API;
- carregamento e erro;
- sessão sem senha;
- persistência após reload;
- rota protegida;
- logout;
- mensagem divertida na área confidencial.
