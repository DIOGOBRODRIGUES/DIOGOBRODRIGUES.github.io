1. Introdução ao Node.js

O Node.js permite a execução de código JavaScript no lado do servidor. Diferente do JavaScript rodando no navegador, aqui temos acesso direto ao sistema de arquivos, rede e processos do sistema operacional.

Para iniciarmos qualquer projeto, o primeiro passo é sempre a inicialização do gerenciador de pacotes:

npm init -y
Dica de Estudo: Lembre-se de verificar sempre o arquivo package.json gerado para entender as dependências do seu projeto.

2. Entendendo o Express

O Express é um framework minimalista que facilita a criação de aplicações web e APIs. Ele abstrai grande parte da complexidade do módulo http nativo.

Exemplo da criação de um servidor básico:

const express = require('express');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
    res.send('Servidor rodando!');
});

app.listen(PORT, () => {
    console.log(`Servidor na porta ${PORT}`);
});

3. Arquitetura de Rotas

À medida que a aplicação cresce, é fundamental separar as rotas em arquivos distintos utilizando o express.Router(). Isso mantém o código limpo e modularizado, um princípio essencial no desenvolvimento de sistemas corporativos.
